# Contributing to ISIRO

This repository accepts contributions to documentation and benchmarks.
ISIRO Runtime, ISIRO Compiler, and `.tic` format are proprietary.

- Open a PR against `main`.
- Sign off each commit (`git commit -s`) under the
  [Developer Certificate of Origin](https://developercertificate.org/).

By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
