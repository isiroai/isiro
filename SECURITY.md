# Security Policy

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/isiroai/isiro/security/advisories/new)
or [security@isiro.ai](mailto:security@isiro.ai). Do not open a public issue.

We aim to acknowledge within 3 business days.

Critical and high severity fixes are coordinated privately before disclosure;
lower severity fixes may ship in public PRs after private report.

This policy covers this repository (docs, benchmarks, install scripts).

For Runtime or Compiler issues, email security@isiro.ai.
